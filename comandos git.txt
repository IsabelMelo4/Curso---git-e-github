

                                      #CRIAR UM REPOSITORIO

git init - você transforma sua pasta em um repositório

git add . ou git add e nome do arquivo - todas as alterações que eu tenha feito sejam rastreadas
(posso fazer isso dentro do terminal)

git status - eu posso ver como esta meu projeto 


                                        #FAZER UM COMMIT 

COMMIT salva as alterações feitas no GIT    
   // git commit -m "sua mensagem"                               

                                        #FAZER UM PUSH 


PUSH - coloca as alterações feitas no git para o gitHub
PULL - pega as alterações feita APENAS no gitHub e não está na minha maquina ainda

Primeira vez fazendo um push para o GITHUB segue esses comandos 

   // git remote add origin + link do repositório
   // git push origin master 

se você estiver fazendo alterações em alguma branch você deve especificar a branch 

   // git push isabel branch
